## 推荐测试路径

### 路径一：需求方预约（需真实已发布服务方）

1. “找高手”切换职业、筛选并打开作品。
2. 进入服务者详情，选择服务和公开档期。
3. 填写姓名、微信或手机号、个性化需求，发送预约。
4. 在“订单 → 预约”查看新订单。

### 路径二：双方状态同步（需两个真实身份及对应支付条件）

1. 使用两个不同的微信测试账号分别登录需求方和服务方；同一账号切换角色不能代替双方隔离测试，也不能向自己下单。
2. 从“订单”打开待处理预约，测试“有意向／要求补充／婉拒”。
3. 有意向后逐项确认时间地点、服务内容、保密选择和金额；需要 NDA 时切回需求方签署，再由服务方签署。
4. 服务端确认真实支付成功后，需求方才能确认执行；再由服务方更新进度并提交交付。支付未接入时在门禁处记录阻塞，不修改数据库伪造已付款。
5. 需求方申请修改或验收，随后提交评价；资金结算另行验收。
6. 服务方在“评价”中回复。

自动化夹具只供显式 `audit=1` 的隔离验收使用，不代表真实账号或订单。不要通过清空本地存储恢复演示订单来验证当前云端版本；测试不得清理用户数据。
