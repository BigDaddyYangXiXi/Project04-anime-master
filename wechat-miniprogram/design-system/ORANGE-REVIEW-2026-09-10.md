# 全局设计契约复审与橙色主题

本文件是本轮主题、金额和验收规则的当前契约。此前米画师改版文件保留为过程记录；有冲突时不得再引用其中的蓝色主色或暖白页面规则。

## 首页迭代的经验：改成执行约束

| 曾发生的问题 | 根因 | 后续必须执行的规则 |
| --- | --- | --- |
| 改边框却修改文字 | 把局部要求解释成重新设计整个组件 | 开始前列出允许修改的属性；修改后检查非目标属性的差异 |
| 文件夹文字未恢复 | 只保持最近一次样式，没有定位用户要求的旧状态 | 恢复操作必须指定旧状态数值；运行时核对默认、选中及互换后的结果 |
| 搜索和筛选看起来不同 | 元素类型、继承链和选择器优先级不同 | 同语义文字使用同一显式类；检查实际计算样式，不能只比较 token 名称 |
| 职业滑动停顿 | 松手等待与动画过程中重复吸附叠加 | 区分用户拖动、动画中、停靠完成；验证阈值两侧与末项 |
| 重编译丢区 | 只验证当次显示，没有检查保存和恢复 | 用户选择必须验证写入、页面重建和冷启动；测试数据与生产数据隔离 |
| 只改颜色，忽视比例和位置 | 参考没有拆成具体信息层级 | 先明确页面任务，再逐项比较头像、图文顺序、间距、操作位置 |
| 订单金额与首页不同 | 本地页脚规则替代了金额规则 | 建立显式金额模块，按语义角色复用，不按页面名称制定金额样式 |
| 规范和展示页相互矛盾 | 新规则追加但旧规则仍自称当前 | 唯一当前契约、历史记录分开；展示页只读取当前 token 和本轮截图 |
| 没有运行时证据就汇报完成 | 把测试通过等同于体验验收 | 代码检查、行为验证、视觉检查分开记录；未通过项目不计入已验收 |

## 当前主题

沿用既有主 Logo 的桃橙色家族，不替换 Logo 或四种职业形象。主色 `#ff946b`，按下色 `#f47c52`，深色前景 `#30170c`；页面、卡片、控件使用暖中性深色。所有值由 tokens.json 管理。

- 主操作、当前状态、链接、导航选中、喜欢选中、轮播指示点共用品牌色。
- 文字与控件背景使用统一中性色；分类插画本身保留各职业色彩。
- 金额采用独立的暖琥珀色 `#ffb66e`。成功、警告、错误保持语义色，不随品牌色机械改橙。
- tokens 命令同时生成 WXSS、原生属性使用的 design-theme.js 和单色操作 SVG；导航 SVG／PNG 由同源脚本生成。测试检查生成结果，禁止只改 CSS 遗漏原生控件。

## 金额模块：一致不等于全部一样大

| 角色 | 共用类 | 尺度与表现 | 使用范围 |
| --- | --- | --- | --- |
| 列表／服务价格 | am-money-list | 34rpx / 44rpx，600，金额色 | 首页卡片、双身份订单列表、兼容订单入口、服务选择 |
| 详情重点价格 | am-money-detail | 44rpx / 60rpx，600，金额色 | 作品详情参考价格 |
| 事实／明细金额 | am-money-inline | 28rpx / 40rpx，600，金额色 | 合作事实、执行明细、项目关联、编辑列表 |

全部使用等宽数字。货币符号、统计口径、分转元和订单金额来源不改变。按钮内的“微信支付 ￥…”仍遵循按钮前景对比度；含金额的完整说明句和可编辑输入保持说明／输入规则，不能把整个句子染成金额色。待核对金额不得伪装成确认金额。

## 边界与仍需持续检查的事项

26 页全部在目录内，模块级审查不等于所有遗留样式已组件化。存量圆角、行距等局部规则仍受债务基线约束；本轮不重设计未授权的布局。身份、付款、结算和数据库业务字段没有改变。

本轮原生截图与交互／计算样式证据统一放在 `.artifacts/orange-contract-2026-09-10`。首尾视口用于全页巡查；关键路径另做实际点击与计算样式验证。真机、全部设备宽度和全部业务状态不能由这些截图替代。

## 本轮验收结果

- 26 页、供需身份合计 30 组原生首尾视口已采集，采集错误为 0；当前模拟器为 430px 宽度。
- 首页与两种身份的订单金额实际计算样式相同：19px、600、rgb(255,182,110)、25px 行高；这是 34rpx 在该设备下的渲染值。
- 另发现详情正文价格被旧标题选择器覆盖成白色，已删除该旧规则；正文与底栏重点参考价均为 25px、600、同一金额色与34px行高（44rpx角色）。
- 实际点击通过：筛选选中／取消、订单分类切换、喜欢切换与恢复、橙色预约按钮进入预约页并返回。
- 65 项自动测试通过；B01 行为契约、20 类模块目录和设计值审计通过，未刷新存量债务基线。
- 证据：capture.json、native-money.json、interactions.json 及同目录 PNG；资金页本轮实屏为待开通／空记录，非空资金记录及四种设备宽度未做本轮完整视觉验收。
