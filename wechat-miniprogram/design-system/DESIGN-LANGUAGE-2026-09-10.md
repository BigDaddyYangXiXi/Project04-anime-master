# 动漫高手：从品牌形象到产品界面

## 这次纠正什么

此前把统一变量、降低局部样式数量当成了设计语言。这只能解决维护问题，不能证明界面协调。品牌插画是桃橙色，按钮偏莓红，导航是粉色立体贴纸，表单还有橙色复选框与紫褐色标题；它们没有共同的语义与造型规则。上一轮“统一”只能算技术基础，不能算整体设计通过。

## 六张米画师实屏的设计拆解

以下结论只来自用户提供的六张截图。相对大小和分组是视觉观察，不把压缩截图推算成米画师的精确设计参数。

| 实屏 | 观察到的设计关系 | 我们借鉴什么 | 我们自己的处理 |
|---|---|---|---|
| 登录 | 单一蓝色主按钮、居中身份、弱化的辅助入口和协议；画面留白围绕登录行为 | 一个明确动作，品牌色在可执行位置出现 | 保留桃色品牌形象；登录按钮、协议链接和选中框来自同一珊瑚色系 |
| 橱窗列表 | 大图是主角；标题、价格、销量层级分明；蓝色筛选与橙色价格各司其职 | 交易信息分层，功能色不与作品图争夺注意力 | 作品图保持原色；珊瑚只承担操作与选择；金额用高对比中性文字，避免所有元数据染成品牌色 |
| 画师列表 | 头像身份→评分→三张作品，重复同一节奏；筛选容器服从同一尺寸 | 同类条目连续阅读、身份结构跨页复用 | 服务方身份、作品预览、档期分工明确；不能把所有内容塞成同一种卡片 |
| 我的 | 信息按身份、资产、合作分组；功能图标同线宽与光学尺寸；品牌趣味集中在少量插画中 | 装饰与工具分层，不把每个入口都画成彩色贴纸 | 立体桃子形象用于品牌与空状态；主导航使用同一套圆端线性图标 |
| 商品详情 | 内容图先行；价格／标题／交期／作者顺序明确；底部收藏弱于购买 | 决策内容与操作分区，强弱动作不混同 | 作者关注、作品喜欢、预约继续各自独立；不复制其商品库存或抢购结构 |
| 画师主页 | 身份信息集中，作品区域连续；底部关注描边、邀请实色，同色不同权重 | 主次动作同源，次动作无需另一种颜色来区分 | 主操作实色，次操作中性面；关注采用品牌文字／描边语义，危险动作独立用警示红 |

不把对方的蓝色、深色背景、品牌图形或版式直接移植。不能由这些静态截图推断其动画、所有错误状态和浅色模式。UIZZE公开入口已查看，但未取得可核验的相关独立实屏，本轮参考主体明确为用户提供的截图。

## 我们的语言：温暖的创作内容，克制的合作工具

### 色彩是语义，不是装饰库存

- 品牌珊瑚：从既有桃橙形象延伸出适合白字按钮的深珊瑚；主操作、选中图标、选中标签、链接同源。
- 暖白／白色／浅中性色：分别用于页面、内容承载、输入与次操作；只用一条轻分隔线建立连续列表，不叠加阴影、描边和底色三种强调。
- 正文与金额：深暖灰。金额通过字号与字重建立重点，不占用“可操作”的品牌色。
- 等待、完成、异常：独立语义色；同时必须有文字，不能只靠颜色识别。状态标签不能与主操作争抢权重。
- 彩虹与立体形象：仅属于品牌插画与活动内容，退出导航、普通按钮和表单选中态。

### 字体、图标与触控共同约束

| 层级 | 本项目设计尺寸 | 使用边界 |
|---|---|---|
| 页面标题 | 22px / 30px，600 | 一个页面的主要标题，避免导航标题下重复同义大标题 |
| 区块标题 | 17px / 22px，600 | 信息组标题，不用于每一行辅助文案 |
| 正文 | 15px / 22px，400 | 需求说明、服务内容与合作条款 |
| 操作文字 | 14px / 20px，600 | 主次按钮；不是把辅助信息全加粗 |
| 辅助信息 | 13px / 18px，400 | 时间、说明、身份补充 |
| 紧凑标签 | 11px / 16px | 非主体信息；重要条款不使用此档 |
| 功能图标 | 24px光学框，1.8px圆端线条 | 同类图标同一构造；激活改色，不放大、跳起或添加彩色底座 |
| 触控 | 至少44px | 图标视觉尺寸与触控面积分开管理 |

文字基线与图标中心对齐；图标不是靠把图片缩到同一个外框就自动一致。每个图形保留接近的墨量、圆端和留白。导航“找高手”可在标准轮廓中加入品牌眨眼细节，订单／项目／档期仍优先让人认出功能。

### 形状与空间

- 常规操作10px圆角，内容容器12px圆角；头像为圆形。胶囊仅用于标签或紧凑切换，不将所有控件胶囊化。
- 页面边距16px；同组8px、内容块12/16px、跨组24px。分组依据阅读任务，而非每个字段都套卡片。
- 主按钮只在本区域的关键下一步出现；选中导航用同一品牌色，但不伪装成一个提交按钮。
- 按压、加载、禁用是同一控件的状态；禁用仍可读，请求中保留位置，不能通过不断换色表达不同状态。

## 实施契约与边界

本轮先落实：语义设计值、主次按钮与选中态、原生和组件导航的统一图标、订单列表的信息色彩，以及登录页的颜色收口。保持所有事件、身份、路由、订单实体和支付规则。导航资源由同一图形源生成SVG与原生PNG，选中颜色读取同一tokens文件。

验收分别记录：设计规则、真实代码接入、当前原生画面与交互。不能把这个契约或自动检查当成全页美学验收；个人中心、复杂编辑层、历史组件局部副本继续按此语言逐一审查，不能自动标记已完成。
