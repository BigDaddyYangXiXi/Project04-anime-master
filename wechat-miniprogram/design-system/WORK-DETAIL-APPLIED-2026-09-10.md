# 作品详情 V2 应用契约（2026-09-10）

用户批准应用V2，并补充：顶部尽量让位于图片、服务方编辑／后端／数据库同步。

## 页面任务及范围
需求方看作品并选择作者服务进行预约；服务方预览自己的发布内容。影响作品详情、作品编辑、已有服务关联编辑及预约预选；不改首页、其他页面字体和支付流程。

## 当前设计
- 顶部仅一行作者头像、昵称、关注，44px头像与关注热区等高；上下间距取space-2。标题、副标题在图集后。
- 图集左右贴边，按原始比例纵向连续阅读，无张数、横向轮播。
- 图集后：标题／副标题 → 正文／参考说明／标签 → 服务区标题与参考次数 → 服务卡及说明 → 编号与右侧复制。
- 关联服务严格沿用已批准HTML圆角卡：全宽、10px圆角、1px细边框、surface底色、上下16px左右12px内边距；名称14px/medium、说明12px/18px、右侧金额使用共享money-list（17px）。无关联或服务方本人预览时隐藏服务卡。
- 固定底栏仅喜欢、当前关联服务参考价、参考作品预约；无全局主导航。work-action-height=128rpx，为业务栏与正文留白提供边界；正文末尾另留28px，安全区另计。服务方预览隐藏社交与预约栏，不保留该栏留白。
- 继续使用品牌橙色与现有字体token，不复制参考网站衬线字或蓝色主题；参考外部图片只在设计研究原型使用，不导入正式作品数据。

## 编辑、接口与持久化映射
| 详情信息 | 编辑入口 | 持久化来源 |
|---|---|---|
| 标题／副标题／正文／参考价／标签／图片顺序 | 服务方作品编辑 | works及work_tags；草稿与发布快照payload.works |
| 作者昵称、头像 | 账号资料 | accounts与媒体实体 |
| 关联服务名称／说明／价格／计价单位 | 橱窗服务项目编辑 | provider_services；发布快照payload.services |
| 作品关联哪项服务 | 服务项目的关联公开作品；作品编辑只读回显当前服务 | service_works；payload.services[].workIds |
| 作品编号／参考次数 | 作品编辑及列表只读 | 服务端编号、订单聚合 |

catalog-read.getWork新增service对象，按当前作者services与work.serviceId匹配；取消关联、服务无效或跨作者匹配失败均返回null。客户端兼容旧接口内provider.services关系；本地预览和草稿预览使用同一关联条件。预约携带作品ID及关联服务ID，原预约页继续校验所属作者和城市可用性。

无新增业务字段，无需数据库DDL或回填。现有一件作品只关联一项服务的保存约束继续有效；不把原型示例时长、人物或价格写入数据库。不新建重复的服务说明／关联服务价格列。

此前错误地把服务卡实现成无框列表并改变了分割线位置；本次恢复批准设计稿，不反向改设计稿迁就实现。

| 对齐项 | 375px设计基准 |
|---|---|
| 图集后标题 | 17px／22px，区域顶部24px、标题顶部6px |
| 正文 | 15px／24px，上下16px |
| 服务区分割线 | 标签后24px，线后24px；1px细线 |
| 服务标题和次数 | 17px／22px标题，次数12px／18px，间隔6px；与卡片间16px |
| 卡内主次文字 | 14px／21px、12px／18px，间隔6px |
| 编号区 | 上外间距24px、顶部分割线1px、上内间距16px，无底线 |

尺寸写入tokens并映射到页面；微信rpx取整允许375px归一化后1px以内误差。自动核验脚本automation/work-detail-design-parity.js，当前证据目录.artifacts/work-detail-parity-20260910。未修改接口、数据库或部署。

## 预约栏价格取值修复

存在关联服务时，服务卡、底部预约栏及预约预选必须取同一个服务实体价格；不得在预约栏混用作品独立展示价。无关联服务时才回退作品展示价。作品编辑价和数据库原值不被覆盖。本次只改本地展示绑定，不部署。回归用例：作品520、关联服务360时，卡片／底栏／预约预选均为360；解除关联后回退520。证据见.artifacts/work-detail-price-20260910。
