# 首页检索与参考术语规范

## 当前职业彩虹外框

用户明确要求顶部职业选中时保留“正在浏览”，并增加彩虹外框。此处为品牌规范普通选中态禁用彩虹的明确例外，仅用于当前浏览职业，不表示在线、认证或接单状态。框宽4rpx，独立置于按钮外侧，跟随原active状态；原文字、按钮尺寸、职业图案和自由横向滚动不变。横滑行两端各保留框宽的空间防止首尾裁切。基础值登记为career-active-frame和career-active-frame-width，不扩大到其他按钮。

## 最新修订：精准修改、地区层级与紧凑控件

本节取代下文冲突的文件夹侧边框和控件尺寸规则。修改边框不授权修改字号／字重等其他属性，已写入项目 AGENTS.md。

- 作品／创作者恢复文件夹改动前的 44rpx；选中 600 字重／主文字色，未选中 500 字重／辅助色；标签随文字内容宽度，左右内边距使用 space-3=24rpx；取消内容区左右侧边，仅保留文件夹头与横向分界。
- 地点采用 40rpx，搜索／筛选采用 26rpx常规字重，拉开任务层级；日期维持原字号。已选地区显示“城市·区”，不伪造默认区；市辖区等占位名不展示。
- 搜索／筛选通过同一个 browse-control-label 元素类控制字色、字号和字重，避免裸按钮文字与 text 元素继承不同规则。可见底块 64rpx，热区保持 touch-min；共同底色与文字颜色来自同一 token。搜索线性图标 28rpx，展开实心小三角 16rpx。
- 区信息沿用 account_discovery_preferences.district_name → account-api 的 districtName → regionValue／locationLabel；城市检索仍沿用既有 cityCode，不擅自增加区级过滤。
- 当前截图和验证记录：.artifacts/precise-controls-2026-09-10。

本规则覆盖此前首页的布局决定。首页任务是按服务城市、时间与职业找到可合作的人，并通过作品判断适配程度。

## 信息顺序

1. 城市、日期：页面内容最上方，并列左对齐，使用检索标题字号 34rpx，与作品／创作者一致；各自保留微信原生选择器。
2. 四职业：沿用妆娘、毛娘、摄影、后期四张既有史莱姆。透明轮廓 SVG 内嵌原始 PNG，保留原像素与源文件；角色直接置于横幅，不套方形容器。角色 100rpx，横幅 324×112rpx，浅色底纹从共享 token 获取。
3. 搜索：职业下方。提示当前职业，提交条件必须携带 career、cityCode、date。切换职业沿用已有职业独立的检索上下文，禁止跨职业混入结果。
4. 作品／创作者切换，随后风格、价格两个筛选按钮，再显示结果。

## 横向停靠

- 手机体验反馈后取消自动定位：四职业使用原生自由横向滚动，松手后按原生惯性自然停止，不再按 50% 阈值吸附或程序回拉。
- 移除为第四张左对齐增加的末尾占位；滚动范围以四张按钮的实际内容为准。滚动本身不切换职业，点击才切换；保留图标、文字、尺寸、间距和选中态。
- 选中态使用品牌描边、深色强调的“正在浏览”；未选中使用辅助色、常规字重的“发现作品与服务”。

# 2026-10-03 筛选实体口径补核
