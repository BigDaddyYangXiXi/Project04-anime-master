# 作品详情图片展示契约

本次用户要求恢复上下浏览，取代此前横向轮播规则。

- 多张图片按原始顺序纵向排列，随整页上下滚动；不使用横向轮播、圆点或横向切换手势。
- 图片上不显示“1/4”等序号覆盖层。
- 详情作者头像使用 `avatar-detail-author`（88rpx），与关注按钮高度一致；有头像与默认头像使用同一尺寸。不影响列表卡片头像。
- 作品编号文字占据剩余宽度，复制按钮清除原生自动外边距并固定在该行最右侧；长编号在文字区域内换行，不推挤按钮。
- 图片区域左右贴齐视口，使用 `media-full-bleed-margin` 抵消详情正文两侧的 `space-4` 留白。作者、说明、价格和操作区保持原有留白与样式。
- 图片铺满宽度，按原始宽高比例自适应高度，不裁切、不拉伸，也不使用固定正方形容器造成左右空白。
- 需求方详情、服务方本人作品及橱窗草稿预览共用这一展示规则；图库字段、排序、权限及数据来源不变，无数据库变更。
- 验证：设计规则检查及相关逻辑测试；手机上的长图、多图和滚动手感仍需当前预览版本实测。
