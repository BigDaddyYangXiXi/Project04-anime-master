# 登录授权排查与品牌页面重做

本地客户端 `0.7.0-native.13`。优先处理用户报告的开发环境登录失败和登录／注册页面设计问题，支付工作暂按原检查点保留。

## 已确认的真实故障

2026-09-07 在微信开发者工具中连接当前工程，实际基础库 `3.17.0`、视口 `390 × 844`。未伪造 SDKVersion、未替换云服务响应。

- 对 `account-bootstrap.getSession` 的真实只读调用返回 `-501003 exceed request limit / EXCEED_REQUEST_LIMIT`。之前被页面归为“网络开小差”，不能将其解释为用户没有授权。
- CloudBase CLI 只读用量检查：计费周期 **2026-08-21 至 2026-09-20**，资源点额度 **3000／3000 已耗尽**；报告总使用量为 3153.01，MySQL 项为 3031.52。这些是工具返回的资源用量字段，不作为人民币金额。
- [CloudBase 官方错误说明](https://docs.cloudbase.net/error-code/EXCEED_REQUEST_LIMIT) 定义为环境请求配额耗尽，需检查套餐用量并按实际情况恢复资源。未购买、续费、调整套餐或关闭数据库。
- 当前设备 `canIUse(button.open-type.getRealtimePhoneNumber)` 返回 true，仅证明组件支持，不能证明企业认证、能力开通和手机号次数包具备。真实页面点击主按钮的自动化检查未取得原生手机号面板或授权回调，手机号授权成功仍待真机证据。

## 页面与流程

参考用户提供的京东授权面板和音乐 App 欢迎／注册层级，复用本项目桃色角色、暖桃欢迎区、奶油底、深色标题和橙黄主按钮。技术用途说明移到点击可读的账号使用说明，明确同意仍保留。参考证据和禁改范围见 [设计契约](auth-redesign-contract-2026-09-07.md)。

- 主按钮改为实际原生 `getRealtimePhoneNumber` 入口，微信身份方式作为文字备用入口。
- 未注册访客先看到登录欢迎页；登录确认尚未注册时进入创建账号。
- 注册缺昵称或缺同意时先展示字段提示，满足后才装配原生手机号按钮，避免提前消费一次性凭证。
- 取消、组件失败、服务不可用分别处理；云配额错误转为“登录服务暂不可用”，原始错误、额度和内部信息不铺在产品页面。
- 输入、身份切换和重复提交在请求期间受保护；失败保留昵称与同意状态，成功沿原有会话和原目标页面返回。
- 原生实际渲染发现按钮默认样式覆盖了宽度／行布局，已用本页作用域修复；说明和底部链接不再错行。移除固定导航高度造成的额外滚动，文字按钮最小触控高度为 44px。

## 前端、服务端、数据库对应

| 页面动作 | 服务端动作及规则 | 数据对应 |
| --- | --- | --- |
| 检查账号／微信身份登录 | getSession／login，可信微信上下文 | 读取既有微信身份和账号；不会静默创建账号 |
| 微信身份注册 | register，昵称及明确同意继续由服务端验证 | 沿用账号、双角色、account-use-v1 同意及微信身份记录 |
| 手机号登录／注册 | phoneLogin／phoneRegister，服务端向微信兑换一次性 code | 沿用手机号指纹、脱敏号码、REALTIME 标识及唯一绑定约束 |
| 云配额失败／授权未完成 | 无成功会话、不伪造账号或转入首页 | 不新增或修改账号数据 |

没有新的业务字段或状态需要迁移，服务端及现有 19 个迁移保持原规则；本轮不创建真实测试账号、不部署云函数。
