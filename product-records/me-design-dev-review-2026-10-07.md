## 几何验收

浏览器实际渲染后读取 DOM 边界，测量容器内缘至首尾内容行框的距离，允许误差1 CSS px。行框不是字体墨迹边界；普通页面剩余高度不算卡片内距。

81项模板 × 两种身份 × 320/375/414px = 486组正常状态样例，不是81个新增生产路由，也不是所有交互状态的穷举。

| 指标 | 修正前 | 修正后 |
| --- | ---: | ---: |
| 框体出现次数 | 654 | 657 |
| 上下距离差超过1px | 186 | 0 |
| 最大上下差 | 16px | 0px |
| 独立行额外缩进 | 39 | 0 |
| 横向溢出 | 0 | 0 |

后测多3次来自服务方资金信息补回。相邻卡片及按钮后卡片另测69次，均为12px。提示卡典型上18/下32px改为16/16px；空段落多出的8px已消除。375px结果样例内容组距主区域上下均231.40625px。结果居中不传播到普通表单、列表。

根因：段落外边距叠加、行内标题行框差、独立行重复缩进、空段落参与gap、按钮后卡片缺少间隔。共享规则使用现有tokens，不逐页补负边距。

证据位于wechat-miniprogram/.artifacts：interior-spacing-before.json、interior-spacing-after.json、spacing-audit.js、interior-dev-review-calendar.png。完整画面检查了档期和结果页；几何通过不等于全部审美验收。

开发顺序：个人中心接已有页面→帮助/设置及必要聚合→新增服务合同及真实能力→接新增表单/结果。不能展开为81个并行新路由。
